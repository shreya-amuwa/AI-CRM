# Security

**Please do not report security problems in a public issue, pull request or discussion.**

Report them privately with GitHub's **Security → Report a vulnerability** on this repository (private vulnerability reporting), or to the
repository owner directly. Include what you found and how to reproduce it; do not access, change or keep data that is not yours.

How the CRM is protected (database rules, keys in environment variables only, no secrets in the code): see `docs/SECURITY.md`.
